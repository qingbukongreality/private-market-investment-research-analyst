# 项目表字段口径

App 生成时以目标总表最上面的第一条正式项目行作为写法少样本，仅对齐句式、详略、换行和单位，不复制该项目的任何事实；本文件的当前规则优先于旧样例。

## 列顺序

| 列 | 字段 | 写法 |
|---|---|---|
| A | 序号 | 接续现有序号 |
| B | 项目简称 | 常用简称，不写冗长公司全称 |
| C | 成立时间 | 以工商登记为准，写真实日期 |
| D | 城市 | 注册地城市，通常不写省份 |
| E | 上市申报预期 | 板块、申报/上市年份；仅有计划时加“计划/预计” |
| F | 前一轮融资时点和估值 | 时间 + 轮次 + 投前/投后估值；多个事项逐行写 |
| G | 已投机构 | 按时间逐行列轮次、投资方、金额；缺金额不补猜 |
| H | 本轮投前估值 | 明确投前/参考估值；口径不明时写“公司表示……” |
| I | 本次融资额（或投后估值） | 优先写融资额；仅披露投后时注明“投后” |
| J | 本次融资截止时间 | 明确日期或管理层计划；无信息留空 |
| K | 主营业务 | 具体产品/解决方案级短语 |
| L | 价值 | 七段式项目摘要 |
| M | 收入 | 最近完整年度实际收入；必要时含当年预计；多年份/多口径逐行写 |
| N | 利润 | 与 M 同期的净利润/亏损；多年份/多口径逐行写 |
| O | 项目来源和录入时间 | `项目来源：...\n录入时间：YYYY年M月D日` |
| P | 是否通过 | 未经用户明确判断留空 |
| Q | 否决原因 | 未经用户明确判断留空 |
| R | 备注 | 只写无法消解的冲突口径；无冲突留空 |

## 主营业务

- 推荐长度：8-30 个汉字；复杂多产品公司最多约 45 个汉字。
- 使用“应用场景 + 核心产品”或“核心产品 + 关键品类”。
- 好例子：
  - `刻蚀设备用硅电极、硅环及CVD-SiC部件`
  - `压电MEMS固态散热器`
  - `玻璃模压非球面/自由曲面透镜及光学模组`
- 避免：
  - `半导体材料`
  - `元器件`
  - `测试机`
  - 把所有规划产品堆成长句

## 价值栏七段式

严格保持顺序：

1. `团队`：公司成立与员工概况；3-5 位最关键成员，每人一句至两句，保留姓名、当前岗位、相关学历/原单位、产业经验和在本项目中的具体分工。团队信息应比其他子项略详细，但不复制完整简历。
2. `股权结构`：实控人及最终受益比例；主要创始股东、员工平台、主要机构股东。相同管理人的基金主体在能够确认时合并说明。
3. `产品`：详细保留具有实质信息的主要产品线、具体产品或型号、用途、关键参数，以及量产/供货/送样/在研状态。主营业务字段的简洁限制不得套用到本段；只删除完全重复或与主营无关的信息。
4. `技术`：核心工艺、性能指标、认证、专利或 Know-how；宣传性结论需降格。
5. `生产、客户`：基地、产线、现有产能、扩产计划；客户按已量产、送样、接触中分层。
6. `市场`：目标细分市场的年份、区域、规模、增速、国产化率；最多保留 1-3 个最相关数字。
7. `收入`：历史实际、当年预计、未来预测分开，注明确认收入/发货/订单口径。

## 简洁度

- 价值栏目标 800-1800 个汉字；产品线较多时允许产品段更长，资料不足时更短，不为凑字数扩写。
- 每个子项优先 1-3 条；团队可适当更长，其他单条通常不超过 60 个汉字。
- 团队写清关键成员背景和分工但不复制完整简历；产品段保留有实质信息的产品、型号、用途、参数及状态；股权不机械抄录全部小股东。
- 用数字和状态词替代宣传形容词。
- 同一事实只出现一次。
- 去掉形容词、副词和判断词。优先写“谁、何时、多少、状态、来源”。
- 能用缩略语就不用全称：BP、纪要、摘要、QCC、财报、工商、官网、公告。
- 不写“优秀、资深、领先、显著、快速、深度、核心、强大、完善、重要、持续”等泛化评价；确需保留时改为可核查事实。
- 信息密度优先：能用 `2025收入5857万`，不写 `公司在2025年度实现了收入5857万元的良好表现`。

## 备注列

- R 列只写 BP 与会议纪要/录音之间无法消解的直接冲突，不再写其他来源差异、资料来源组合、一般缺失项、分析判断或核查建议。
- 多个冲突逐行写，每行以 `冲突：` 开头并同时注明双方口径；例：`冲突：收入BP为1.2亿；会议纪要为确认收入0.8亿`。
- 没有未消解冲突时 R 列留空。

## 留空规则

- F-J、M-N 无可靠信息时留空，不写 `0` 或任何缺失占位语。
- L 内某一段无可靠信息时只保留固定段标题，不写 `暂无可靠披露` 等占位内容。
- 所有列禁止使用 `暂无披露`、`未披露`、`未提及`、`材料未说明`、`待补充`、`待确认`、`不详` 等缺失占位语；对应单元格直接留空。
- O 缺项目来源时不写占位语，只保留实际录入日期。
- P-Q 默认留空。
- R 无冲突时留空。
