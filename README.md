# 投研项目工作台

面向一级市场项目的本地 Mac 工作台。将录音原文、BP、公司简介、股权图及补充材料放入项目文件夹后，可独立生成：

- 严格模板化的 Word 会议纪要及完整 Q&A
- 按既有项目表格式追加的 Excel 项目录入

## 主要能力

- 会议纪要与项目录入可独立运行
- 项目录入先生成到输出文件夹；人工确认后写回输入根目录的原始总表，并自动保留时间戳备份
- 使用 BP 和团队资料校正录音原文中的姓名、职务及专业术语
- Q&A 按访谈顺序保留问题、追问、解释、数字和限定条件，仅清理口语噪音
- 支持 PDF、DOCX、PPTX、XLSX 和常见图片材料
- 支持 DeepSeek 与 MiniMax，可在 App 内更换 API Key 和模型
- 输入、输出路径可配置，API Key 仅保存在本机 App 数据目录

## 本地开发

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run desktop:build
npm run desktop:open
```

网页开发界面：

```bash
npm run dev
npm run dev:backend
```

## 构建 Mac App

```bash
npm run desktop:package
```

也可使用：

```bash
zsh scripts/build-mac-app.sh
```

构建产物位于 `mac-app/`，该目录不进入 Git 历史。

## 文件夹约定

输入根目录下，每个项目使用一个同名子文件夹。用户需要自行准备模板，并放在输入根目录：

- `会议纪要模板.docx`：提供会议纪要的 Word 页面、字体和样式。
- `项目表录入.xlsx`：作为项目录入总表，App 会在末尾追加新项目。

模板只从用户电脑本地读取，不包含在公开仓库中，也不会发送至 AI 服务商。生成结果默认写入输出根目录下对应项目文件夹。

## 数据与密钥

- 项目材料会发送给用户自行配置的 AI API 服务商以完成生成。
- API Key、运行设置、项目材料、录音和生成结果均不提交到本仓库。
- Word、Excel 模板由用户自行准备，不提交到本仓库。
- 请勿把真实项目材料放入本仓库；建议只通过 App 选择仓库外的输入、输出文件夹。
- `.gitignore` 已排除常用的本地资料目录，但提交前仍应使用 `git status` 人工确认文件清单。
- 提交或分享会议录音前，请确认已取得必要授权。
